# BiblioMail · Demo

Demo navegable de BiblioMail, la plataforma de correo institucional de Bibliotecas Duoc UC.

**Entrar:** `jletelier` / `admin` (administrador) · `operador` / `operador` (operador)

Es una demo sin servidor: ningún correo se envía, los contactos son ficticios y todo lo que se crea queda
guardado sólo en el navegador de quien la usa (botón «Reiniciar demo» para empezar de cero).
Este repositorio contiene sólo la versión compilada de la interfaz.
